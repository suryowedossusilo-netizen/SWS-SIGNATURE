# AGENT.md — SWS-SIGNATURE

## Design
Editorial, professional, understated, human. Warm off-white, charcoal, muted neutrals, restrained terracotta, clear typography, whitespace, responsive layouts. Avoid cinematic effects, WebGL, excessive animation, gradients, and clutter. Respect accessibility and reduced motion.

## Technical constraints
Static HTML, CSS, vanilla JavaScript. No framework, build system, analytics, trackers, forms, or cookie banners without approval. Keep relative paths GitHub Pages-compatible. Preserve existing assets and license attribution.

## Content integrity
Never invent employment, dates, education, certifications, metrics, testimonials, clients, or outcomes. Never claim RDP / remote desktop experience. Use “nearly five years”, not “5+ years”. Keep the UWP S1 degree in progress. Keep project statuses accurate. Do not generate or alter the user's identity photo.

## Git safety
Main only; no branches. Never add secrets, .env, private keys, or database dumps. Do not delete files or alter repository settings without approval. Report exact changes and checks.
