# GitHub Pages

1. Repository Settings → Pages.
2. Choose Deploy from a branch.
3. Select `main` and `/(root)`, then save.
4. Wait for the Pages deployment workflow.
5. Visit https://suryowedossusilo-netizen.github.io/SWS-SIGNATURE/.

Local preview: `python -m http.server 8000` from repository root. The portfolio uses CDN libraries; CV pages support browser Print → Save as PDF. GitHub Pages does not apply Cloudflare-specific headers or redirects.
