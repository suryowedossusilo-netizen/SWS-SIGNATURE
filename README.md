# SWS-SIGNATURE

Professional CV and cinematic portfolio for **Suryo Wedo Susilo**.

- `index.html`: cinematic portfolio, adapted from Sea of Stars.
- `main.js`: Three.js starfield, GSAP / ScrollTrigger, Lenis, scroll effects, case-study overlays and education accordion.
- `cv/index.html`: corporate executive CV with profile photo and print-to-PDF support.
- `cv/ats.html`: text-first ATS-friendly CV.
- `cv/cv.css`: shared CV styles.
- `images/profile.jpg`: existing profile photo.
- `images/project-*.svg`: custom illustrative project covers.
- `docs/`: design, content and deployment notes.

## Preview
Open `index.html` locally, or run `python -m http.server 8000` from the root. Enable GitHub Pages via Settings → Pages → Deploy from branch → `main` → `/(root)`.
