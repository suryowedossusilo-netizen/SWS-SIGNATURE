# SWS-SIGNATURE

**THE GUARDIAN'S OATH** — a cinematic portfolio for Suryo Wedo Susilo, built around an interactive 3D samurai character.

- `index.html`: narrative portfolio, professional experience, selected projects, education and contact.
- `cv/index.html`: designed CV.
- `cv/ats.html`: text-first ATS CV.
- `AGENT.md`: project rules and creative direction.
- `.agents/skills/design-taste-frontend/SKILL.md`: pinned official Taste Skill instructions.
- `.agents/plugins/taste-skill`: full upstream Taste Skill package pinned as a Git submodule.

## 3D character
The hero loads the Samurai Commander model from 3DAssets.dev. The model is 3.9k triangles, includes idle/bow/wave animations and is released under CC0 1.0. It is loaded through Google's model-viewer and hosted on the model provider's CDN. The character is a metaphor for discipline and service, not a biographical claim.

GitHub Pages serves the static files from the repository root.
